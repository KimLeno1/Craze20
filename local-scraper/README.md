# Local Scraper

This is the extracted scraper from the main application. It has been moved here to run locally.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the scraper server:
   ```bash
   npm start
   ```

The local scraper API will run on `http://localhost:4000`.

## Notes
The `mock_db.ts` file replaces the production database with mock functions so it can run independently.
