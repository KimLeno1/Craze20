# Closet Kraze: High-Fidelity Flyer & Poster Design Prompts (7 Concepts)

This document contains **7 conversion-focused, high-contrast prompt blueprints** for marketing flyers, lookbook posters, and digital display ads. Each concept includes a **detailed AI image generation prompt** (for tools like Midjourney, DALL-E, or Gemini), visual layout structures, color swatches, typography guidelines, and bold human-centric copywriting.

---

*   **Vibe:** Minimalist, Swiss, architectural, industrial streetwear.
*   **Best For:** Wall posters in physical stores, high-end lookbooks, and Pinterest ads.

```markdown
### 1. Midjourney / Gemini Image Generation Prompt

*   **Grid Structure:** Dynamic asymmetrical layout. The imagery occupies the left 2/3 of the frame, bordered by a sharp neon-cyan rule lines on the right separating it from clean tabular text.
*   **Typography:**
    *   **Headline (Display):** Space Grotesk (Bold, tightly tracked) - "CURATED SILHOUETTES / ARCHIVE 2026."
    *   **Body (Details):** JetBrains Mono (Semi-bold, clean) - "Technical weight, weather-tested materials."

### 3. Copywriting & CTA
*   **Main Copy:** "POSTURE CODES UNLOCKED. DISCOVER THE NEXT TRANSITION IN THE SYSTEM."
*   **Call-to-Action:** "Swipe path or enter code 'BRUTALIS' on Closet Kraze for 10% value recovery."
```
